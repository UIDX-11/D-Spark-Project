# Glossary (术语字典)

This file is the **single place** to define:

- Preferred term (推荐用词)
- Aliases / synonyms (同义词)
- Forbidden terms (禁用词)

## Terms

| Preferred | Aliases | Forbidden | Notes |
| --- | --- | --- | --- |
| Select | dropdown, picker, combo box | - | Use “searchable select” when it has a search box |
| Switch | toggle, on/off | - | Use for boolean, immediate effect |
| Badge | indicator, count badge, status dot | - | Count vs dot vs status must be explicit |
