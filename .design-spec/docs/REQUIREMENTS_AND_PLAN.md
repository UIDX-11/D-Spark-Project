# D-Spark design-spec · 需求拆解与需求计划

本文档与混合规格 / 可移植 Agent Skill 路线对齐，用于「要什么 → 怎么排 → 落到哪」的对照。真源实现分散在 `.design-spec/` 与 `.cursor/skills/`；**不替代**具体组件 md 或 Figma 表。
