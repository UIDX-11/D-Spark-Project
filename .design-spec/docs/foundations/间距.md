# 间距（Spacing）

全局间距尺度与页面/组件边距规则真源。组件级 **Space** 用法见 `[../components/space.md](../components/space.md)`。数值真源：`../../tokens/src/core.json`、`semantic.json`（`semantic.layout.*` 等）。

## Do

- 使用 `**--core-space-*`** 与已解析的 `**--semantic-*`** / `**--component-***` 表达 padding、margin、gap；在 HTML demo 中与 `[page_templates.css](../../generator/page_templates.css)` 一致时用 `calc(var(--semantic-font-size-*) * 1px)` 等同模式处理字号类 token。
- 页面外边距、区块间距优先与 `[布局.md](布局.md)`、`[栅格.md](栅格.md)` 中的 region 约定一致。
- 变更尺度时先改 `tokens/src`，再运行 `python3 ../../tokens/generate_tokens_css.py`，并更新相关组件 md 中的比对表。

## Don't

- 在受治理的 demo/规格中把间距写死为裸 `px` 而不标为待对稿例外（见 `scan_token_violations`）。
- 用任意数值 gap 替代已定义的 `**semantic.layout.buttonGroupGap**` 等语义键，除非组件 md 明确允许。

```json
{
  "schemaVersion": "0.1.0",
  "kind": "tokenMap",
  "numericToToken": [
    { "role": "spacing-8", "valuePx": 8, "token": "--core-space-2", "note": "示例：与 core 对齐时核对 dist/tokens.css" },
    { "role": "spacing-16", "valuePx": 16, "token": "--core-space-4", "note": "示例" }
  ]
}
```
