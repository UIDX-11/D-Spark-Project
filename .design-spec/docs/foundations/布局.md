# 布局（Layout · 宏观）

**全库页面拓扑与区域模型**（shell、region、主从/顶栏侧栏）。  
**Arco Layout 组件 API** 见 `[../components/layout.md](../components/layout.md)`；**页面模版叙事**见 `[../layouts/](../layouts/)`。

## 区域模型

- **Shell**：顶栏、侧栏、内容区、（可选）底栏；全局导航区域跨页保持稳定。
- **Content region**：承载主任务；内部再按 **栅格**（`[栅格.md](栅格.md)`）切列。
- **Master–detail**：左树/列表 + 右详情时，侧栏宽度与折叠行为写入 `responsive` / `layoutProtocol` 块。

## 与栅格的关系

- 页面壳层确定 **region** 后，在内容区应用 `**gridColumns: 12`（默认）或显式 `24`**。
- Figma **Fill container / Hug contents** 与 Web 映射见 [layout-protocol-reference.md](layout-protocol-reference.md) 与 `.design-spec/schemas/examples/layout-protocol.example.json`。

## Do

- 新页面先在 IA 或 `page.md` 中固定 **templateId**、**demoPath** 与 **Figma** frame，再展开组件组合。
- 间距与内边距遵循 `[间距.md](间距.md)`。

## Don't

- 在内容区混用无文档的自定义列数（非 12/24）。
- 省略侧栏折叠/响应行为导致小屏横向滚动（除非业务例外并在 md 中声明）。

```json
{
  "schemaVersion": "0.1.0",
  "kind": "page",
  "templateId": "dashboard-shell",
  "layoutShell": "sidebar-fixed + header + scrollable-main",
  "regions": [
    { "id": "main", "patterns": ["pro-table"], "gridColumns": 12 }
  ],
  "demoPath": "../../demos/pages/dashboard.html",
  "figma": {
    "fileKey": "KJfy0GFDs8kLsXTzhTxAjd",
    "note": "补充具体 page frame node-id"
  }
}
```
