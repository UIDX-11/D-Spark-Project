# 投影（Elevation / Shadow）

表面层级与阴影语义。具体 **组件** 阴影 token 见 `tokens/src/component.json` 中 Card、Modal、Dropdown 等条目；本文定义 **原则** 与缺口处理。

## 当前状态

- 组件域已存在若干阴影相关 token（随 `component.json` 演进）。若某表面无 token，在组件 md 中标 **TBD**，并跟踪 `tokens/src` 任务。
- **z-index / 堆叠**：Modal、Dropdown、Message、Drawer 等叠加顺序须在组件规格与 demo 中一致；后续可单独抽出「堆叠」附录。

## Do

- 同一交互层级（如浮层）内，阴影深度与 `z-index` 策略保持一致。
- 在 Card / Modal 等 md 中引用具体 `--component-*-shadow`*（若已定义），避免重复粘贴长表。

## Don't

- 在规范 HTML 中为抬升表面手写 `box-shadow: …` 裸值而不绑定 token 或标注待对稿。
- 多个浮层组件使用未文档化的任意 z-index。

```json
{
  "schemaVersion": "0.1.0",
  "kind": "tokenMap",
  "numericToToken": [
    {
      "role": "card-elevation",
      "token": "--component-card-shadow",
      "note": "以 dist/tokens.css 实际变量名为准；缺失则 TBD"
    }
  ]
}
```
