# 栅格（Grid）

Web 端仅支持 **12** 与 **24** 列两种等分栅格；与结构化规格中的 `gridColumns` 枚举一致。

## 12 等分栅格

- 整页由 **12** 列等分。
- 适用于 **业务信息分组较少** 的中后台页面（列表、常规表单、标准 Dashboard）。

## 24 等分栅格

- 整页由 **24** 列等分。
- 适用于 **业务信息量大、场景复杂** 的页面（高密度筛选、多面板、复杂仪表盘）。

## 规范约束

- `**gridColumns` 仅允许 `12` | `24`**；禁止 8、16 等（除非未来 major 扩展）。
- **默认一律 `12`**。仅当 `page.md` 或 `kind: responsive` 中 **显式声明 `gridColumns: 24`** 时方可使用 24；未声明时生成与评审按 12 列处理。
- 与 `[../pages/information-architecture.md](../pages/information-architecture.md)` 交叉引用，避免页级与组件级 responsive 块冲突。

## Do

- 在 `page` / `responsive` 块中写明 `gridColumns` 与断点下的 `maxWidth`、侧栏折叠策略。
- Figma Auto Layout 与 Web 的 span 映射时，优先整列对齐，减少半列漂移。

## Don't

- 在未声明的情况下默认使用 24 列。
- 混用 12/24 于同一页面壳层而不在规格中说明。

```yaml
schemaVersion: "0.1.0"
kind: responsive
breakpoints:
  - name: md
    minWidthPx: 768
    gridColumns: 12
    note: "默认；复杂页在 page 规格中覆盖为 24"
```
