# Intent Index (Intent → Patterns → Components)

Use this index when the request is described as an **intent** instead of a component name.

## CRUD list page (B-end)

- **Patterns**
  - Filter bar + result table/list
  - Bulk actions + row actions
  - Empty state + loading + error
- **Components**
  - Layout, Space, Card
  - Form, Input, Select, Checkbox, Cascader
  - Table, List, Tag, Tabs

## Detail page (read-heavy)

- **Patterns**
  - Header summary + sections
  - Definition-list style fields (label/value)
  - Sticky anchors for long pages
- **Components**
  - Layout, Space, Card, Tabs
  - Data Display (Number), Tag

## Data entry flow (forms)

- **Patterns**
  - Progressive disclosure (basic → advanced)
  - Inline validation + submission errors
  - Save/Cancel affordances
- **Components**
  - Form, Input, Select, Checkbox, Cascader
  - Button

## Navigation inside a module

- **Patterns**
  - Tabbed sub-pages
  - Left-tree + right-content master/detail
- **Components**
  - Tabs, Tree, Layout, Card
